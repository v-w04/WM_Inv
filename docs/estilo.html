Cómo usarlo en otra app

Copia theme.css y enlázalo antes de tus estilos:

<link rel="stylesheet" href="theme.css">   <!-- primero -->
<link rel="stylesheet" href="style.css">   <!-- después -->

En tu CSS, consume las variables en vez de escribir colores:

/* ✅ así */
.mi-panel {
  background: var(--surface-card);
  border: 1px solid var(--border-default);
  color: var(--text-primary);
}

/* ❌ nunca así */
.mi-panel {
  background: #1a2029;
  border: 1px solid #30363d;
}

Para cambiar el look de todas las apps: edita un valor en theme.css y se propaga solo.
